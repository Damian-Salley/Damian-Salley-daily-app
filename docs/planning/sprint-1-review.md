# Sprint 1 Review

## Sprint Goal

Enable students to manage their subjects and view their study progress so that they can organise and track their studies effectively.

## Sprint 1 Stories

The Sprint 1 stories are:

- Create a subject
- View subjects
- Rename a subject
- Delete a subject
- View subject progress

## What Is Demoable

The Sprint 1 stories have been clearly defined as user stories with acceptance criteria and story point estimates. The planned functionality would allow a student to create, view, rename and delete subjects, as well as view the progress of a subject.

The actual development of these features has not yet been completed, so I would not currently consider the full Sprint Goal achieved or the features ready for a final demonstration.

## Sprint Goal Review

The Sprint Goal gives the sprint a clear focus on Subject Management and study progress. The stories support this goal, but the functionality would need to be implemented and tested against the acceptance criteria before the Sprint Goal could be considered complete.
