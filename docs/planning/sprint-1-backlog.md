# StudyFlow Sprint 1 Backlog

## Sprint Goal

Create the basic Subject Management functionality for StudyFlow.

## Ready for Sprint 1

### Create a Subject
Allow the student to enter a subject name and create a new subject. The subject must have a name and an empty name should not be accepted. After creation, the new subject should appear in the student's subjects.

### View Subjects
Display all created subjects, including each subject's chapter count and study progress. If no subjects exist, show a message and provide an option to create a subject.

### Rename a Subject
Allow the student to select an existing subject and enter a new name. If the new name is empty, the change should not be saved and the subject should return to its original name.

### Delete a Subject
Allow the student to select an existing subject and choose to delete it. Before deletion, StudyFlow should ask the student to confirm the deletion and warn that the subject cannot be recovered or restored once deleted. The subject should only be deleted after the student confirms.

## Wanted for Sprint 1 but Not Ready

### Create a Chapter
I wanted to include creating chapters in Sprint 1, but the Product Backlog item does not currently contain enough detail to meet my Definition of Ready. The required inputs, expected result, and handling of invalid input would need to be clarified before it is added to a sprint.
